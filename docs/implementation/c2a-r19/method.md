# r19 method and commands

The Gate 3 r18 review was read first. HEAD was `9ebf85a0720a6cefdf07a8ab10e0d2fbf38b474e` and the starting worktree was clean. SHA-256 hashes were captured for all 1,746 starting tracked files before edits. HEAD and the complete index inventory were captured too. No existing test, fixture, evidence file or completion marker is edited. All new evidence lives in this directory.

The original 140-case veto matrix and 16 PDF collision checks ran against unchanged production c2a.18, followed by 40 normalization/page-boundary checks. Their JUnit files preserve 112 failures and 84 passes before any production fix. Subsequent separator and mapped-role checks also failed before their respective guard additions. The 480-case competition tests were added when the exact reviewer generator became available; their historical c2a.18 assertions produce 108 failures / 372 passes in isolated modules. Those are historical replay results, not a claim that production was still c2a.18 when the later tests were added.

`check_evidence.py` reads the untouched earlier generators and archived results, but never calls their `main()` functions. Every historical r18 outcome and family total is checked against its archived r18 result. Isolated worker packages are created only in this new directory and removed by `TemporaryDirectory` / `ExitStack`. Historical production sources come from `git show`; the worktree source is never replaced to run a counterfactual.

The candidate is exactly the reviewer's one-line change from `if other is block or not heading_crosses_gutter(other, blocks):` to `if other is block:`. The final implementation restricts competition to the same page, as requested. The measured narrower variant keeps r18 crossing competitors, adding non-crossing matches only when their local score is zero and excluding mismatched/ambiguous printed names and unresolved-person vetoes. It fails the veto and competition families and is rejected.

The exact review inputs `/tmp/rev18/q3.py` and `/tmp/rev18/q8.py` were read as inputs to the expressly requested reproduction. Their bytes and hashes are preserved here. The q3 generator functions `two_col`, `l1_cases`, `f_fine`, and `competition` were copied verbatim into the new test-support module; their ASTs are checked against the input snapshot. The old harness is never executed or imported: it asserts that production is still r18 and creates scratch workers outside this repository. The original source files remain unchanged.

These exact generators reproduce 3,480 Pat-boundary cases, 1,800 Fleet-boundary cases, two 3,456-case F sweeps and the 480-case competition family. Baseline assertions pin the review's 94 Pat-boundary wrong placements, 192 Fleet-boundary wrong placements, and 348/300 raw competition flags for r18/candidate. The early 5,400-case reconstructed boundary and reconstructed F sweep remain archived as exploratory evidence; they are not substituted for the exact reviewer families.

The original `wrong_fields` oracle and each original `allowed` mapping remain unchanged. The competition output records **both** raw flags and adjudicated flags. Its only exception requires all of: the original heading is absent, literal `COMPANY`, or unmapped `RECIPIENT:`; Pat has no supplied legal company; and every raw wrong field is Pat's signature/date on the sole Harbor-named affiliate rule. This implements the user's explicit no-Harbor-heading example. All 300 candidate residuals are listed individually; 60 known-company collisions hold and 240 sole-domain-company cases are justified. Independent controls add Pat's explicit Analytics company and verify that Group-only placement then holds.

Final evidence is in `release-summary.json` / `release-cases.json` and `release-review-summary.json` / `release-review-cases.json`. `check_release.py` and `check_exact_release.py` rerun the exact final source, reusing already-measured historical alternative outputs only when the variant source hashes match. All final variants' hashes are cross-checked during finalization. Earlier `preflight`, `counterfactual`, `final`, `reconstructed`, and `exact-review` artifacts are retained to show the iterations and are not the final-source certification.

All replay runners remove `OPENROUTER_API_KEY` and `PLACE_MODEL`, replace `httpx.Client.send` with a failing mock and verify zero calls. Model responses are deterministic local mocks. The unusual-label golden still exercises its model path. Seven goldens are compared to `c2a-r13/placements.json` ignoring only `analysis_version`; native fields are compared exactly. Real workers are checked for the goldens, both r18 B1 reproductions, 14 veto cases in both r18 and the final source, and every candidate collision case in the competition family.

The full suite uses no `-x`, maximum-failure override, selection filter, skip or replacement fixture. A source hash was recorded when the final full-suite run started; finalization requires it to match production and both final replay sets. JUnit is parsed for failures, errors and skips, and every prior r18 test node must still exist. The launcher's pre-existing scratch-directory warning is preserved in the logs; it does not prevent test completion. Finalization hash-verifies the protected files, HEAD, index, memory and review inputs, writes the result report, and writes the new `.done` marker last.
